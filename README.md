# Kinopoisk Watch

Лёгкое расширение для Chrome, которое добавляет кнопку **«Смотреть»** на страницы фильмов и сериалов kinopoisk.ru
Один клик — и тот же фильм открывается на другом сайте с сохранением пути:

`kinopoisk.ru/film/xxx/` → `your-site.com/film/xxx/`

## Возможности
- Кнопка сразу после установки!
- Работает на страницах `/film/` и `/series/`
- Сайт для перехода меняется в меню расширения
- Без слежки и сбора данных — локально хранится только адрес выбранного сайта

## Установка
1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте
2. Откройте `chrome://extensions`
3. Включите **Режим разработчика**
4. Нажмите **Загрузить распакованное расширение** и выберите папку расширения

## Смена сайта
Нажмите на значок расширения на панели, введите домен (например, `example.com`) и нажмите **Сохранить**.
**Сброс** возвращает сайт по умолчанию.
